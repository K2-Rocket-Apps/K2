# Security policy

## Reporting a vulnerability

Please email **support@k2-tek.com** with a description of the issue and steps to reproduce. Do not open a public issue for security reports. We will acknowledge your report and keep you informed while we investigate.

## What this package contains

- No secrets, tokens or credentials of any kind.
- No MCP server entry. Your gateway URL is configured locally on your machine by `k2-agent connect`; this package never handles a token.

Releases are published from immutable `v*` tags.
